# Nghe-Nhan Truong Portfolio — recovered V8

Recovered from two Chrome **Webpage, Complete** exports supplied by the website owner (homepage + VLA detail). This is **not** the original ChatGPT Sites development repository.

## Run on Windows (VS Code)
1. Open this folder in VS Code.
2. Open a terminal and run `py -m http.server 8000` (uses preinstalled Python, if available).
3. Browse to http://localhost:8000/ .
4. Test `project.html?id=vla`, theme switch, image display and navigation.

No Node.js, npm, or build/compile step is needed for this recovered static copy. If Python is unavailable, use VS Code Live Server as an optional alternative.
